# monkeyseemonkeydo

Monkeytype-style touch typing course for the **Swedish keyboard** — 15 pro lessons
from the home row to the entire keyboard, adapted from the classic typingme.com
lesson progression.

## Features

- 15 lessons: home row → g/h → ä → shift → top row → bottom row → numbers → symbols → everything
- Randomly generated drills per attempt, weighted toward each lesson's new keys,
  mixed with real Swedish words once their letters are unlocked
- Live WPM and accuracy, monkeytype-style results screen
- On-screen Swedish (sv-SE) keyboard with next-key highlight, plus hands showing
  which finger to use (including shift with the opposite pinky and altgr)
- Pass a lesson by clearing it with **no mistakes in under 60 seconds**
- Progress (best WPM, pass status) saved in localStorage
- `tab` or `ctrl+r` restarts with a fresh drill; browser refresh stays on the lesson
